反汇编取证方式：

```bash
dexdump -d <jar 解出的 classes.dex> > dump.txt
grep -oE "Lcom/github/catvod/(net|crawler|js)/[A-Za-z0-9_$]+;\.[^ ]*" dump.txt | sort -u
```

- 继承关系只有一条：两 jar 共 **111 个 spider 类全部 `Superclass: Lcom/github/catvod/crawler/Spider;`**；**没有任何 jar 类实现宿主接口或继承别的宿主类** ⇒ 全仓只有 `Spider` 必须非 final（已实证）。
- 宿主成员引用合计 21 项：`Spider` 14 / `SpiderApi` 5 / `SpiderDebug` 2（清单见规范 §7.20）。逐条到新字节码核对：**21/21 命中且描述符一致**。
- 另实测：`Spider.client()`、`Spider.empty`、`Spider.siteKey`、`net/OkHttp`、`crawler/js/*` 在这两个 jar 里**都没有被直接引用** —— Tier A 面比计划预估更小，但 `Spider` 的 14 项一个都不能少。

## 5. 复核轮账目（两个独立只读子代理，逐方法对照 Java 原文）

| 严重度 | 数量 | 条目 |
| --- | --- | --- |
| 阻断 | 0 | — |
| 高 | 1 | `HtmlParser.parseDomForList` 列表文本用 Kotlin `trim()`（按 Unicode 空白裁）而非 Java `String.trim()`（只裁 `<= ' '`）⇒ 含 `&nbsp;`/全角空格的 HTML 文本会被多裁。**已修**（`04718c6`） |
| 中 | 1 | `Json.safeString` 同因（作用于 header/form 参数值）。**已修** |
| 低 | 4 | ① `JarLoader`/`JsLoader` 的 md5 `trim()` 同因（十六进制输入下无实际差异）**已修**；② `Spider` 的 `pg`/`id`/`action` 非空入参生成 `checkNotNullParameter`（调用点全传非空、jar 覆盖后不执行基类体 ⇒ 不可达）；③ `Req.getPostType/getMethod`、`Res.getContent` 的 `!!`（仅 JVM 单测里 `TextUtils` 是桩时不可达）；④ `Connect.cancelByTag` 的 `tag!!`（唯一调用点传非空） |
| 口味 | 2 | ① `Connect.success` 用 `Charset.forName` 替代 `String(bytes, charsetName)`：非法字符集时异常类型不同（`UnsupportedCharsetException` vs `UnsupportedEncodingException`），均落同一 `catch (Exception)` ⇒ `error(ctx)`；② `JarLoader.proxyInvoke` 的 `!!` NPE 点位（与 Java 的 `ConcurrentHashMap.get(null)` 同因同果） |

**子代理逐点确证等价的部分**（无需改动）：split 全走 `RegexUtils.getPattern(x).split(y)`；`getBytes()`/`toLowerCase()` 全对齐 `Charset.defaultCharset()`/`Locale.getDefault()`；`replaceAll(regex,"$1")` ≡ `Regex.replace(...,"\$1")`；反射 vararg 全 `*args`；okhttp 5 的 `toHeaders`/`toMediaTypeOrNull`/`toRequestBody`/`toHttpUrlOrNull`/`.dispatcher`/`.body` 替换的 null 边界与抛点一致；`JsSpider`/`Global`/`Trans`/`Crypto`/`Async`/`FunCall`/`local`/`OkHttp`/`Proxy` 全类逐方法无差异。

**收敛结论**：修复后复跑构建 + 单测 + `javap`（655/0/0/1、旧有新无 = 0）；剩余发现全属**低（不可达或仅异常类型/点位）**或**口味** ⇒ 达到计划规定的收敛终止线。
