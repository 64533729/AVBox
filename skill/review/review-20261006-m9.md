反汇编取证方式：

```bash
dexdump -d <jar 解出的 classes.dex> > dump.txt
grep -oE "Lcom/github/catvod/(net|crawler|js)/[A-Za-z0-9_$]+;\.[^ ]*" dump.txt | sort -u
```

- 继承关系只有一条：三个 jar 共 **179 个 spider 类全部 `Superclass: Lcom/github/catvod/crawler/Spider;`**；**没有任何 jar 类实现宿主接口或继承别的宿主类** ⇒ 全仓只有 `Spider` 必须非 final（已实证）。
- 宿主成员引用合计 21 项：`Spider` 14 / `SpiderApi` 5 / `SpiderDebug` 2（清单见规范 §7.20）。逐条到新字节码核对：**21/21 命中且描述符一致**。`源码/1.jar` 的引用面是这三者的子集，独立复核一致。

## 5. 复核轮账目（三个独立只读子代理，逐方法对照 Java 原文）

| 轮次 | 角度 | 结论 |
| --- | --- | --- |
| 1-A | 契约与加载器：`Spider`/`SpiderApi`/`JarLoader`/`JsLoader` | **阻断 0 / 高 0 / 中 0**；2 低 + 1 口味 |
| 1-B | JS 桥与网络栈：`JsSpider`/`Global`/`Connect`/`HtmlParser`/`Trans`/`Json`/`Req`/`Res`/`Crypto`/`Async`/`FunCall`/`local`/`OkHttp`/`Proxy` | **阻断 0**；1 高 + 1 中（`trim()` 语义）+ 2 低 + 1 口味 |
| 2（修复轮） | 修完 6 处 `trim()` 后复跑构建 + 单测 + `javap` | 655/0/0/1、旧有新无 = 0 |
| 3 | **换第三角度**：装箱比较/数值解析与进制/字符串 API 边界/集合迭代顺序/反射与类初始化时点/异常控制流 + 逐例复核第 2 轮那 6 处 `trim` | **本轮无 阻断/高/中**；2 低/口味 |

| 严重度 | 数量 | 条目 | 处置 |
| --- | --- | --- | --- |
| 阻断 | 0 | — | — |
| 高 | 1 | `HtmlParser.parseDomForList` 列表文本用 Kotlin `trim()`（按 Unicode 空白裁）而非 Java `String.trim()`（只裁 `<= ' '`）⇒ 含 `&nbsp;`/全角空格的 HTML 文本会被多裁 | **已修**（`04718c6`） |
| 中 | 1 | `Json.safeString` 同因（作用于 header/form 参数值） | **已修** |
| 低 | 4 | ① `JarLoader`/`JsLoader` 的 md5 `trim()` 同因（十六进制输入下无实际差异）；② `Spider` 的 `pg`/`id`/`action` 非空入参生成 `checkNotNullParameter`（调用点全传非空、jar 覆盖后不执行基类体 ⇒ 不可达）；③ `Req.getPostType/getMethod`、`Res.getContent` 的 `!!`（仅 JVM 单测里 `TextUtils` 是桩时不可达）；④ `Connect.cancelByTag` 的 `tag!!` 被提到 `if (client != null)` 之外（Java 只在分支内解引用） | ①**已修**；④**已修**（`28fad04`）；②③ 保留（不可达，登记） |
| 口味 | 2 | ① `Connect.success` 用 `Charset.forName` 替代 `String(bytes, charsetName)`：非法字符集时异常类型不同，均落同一 `catch (Exception)` ⇒ `error(ctx)`；② `SpiderDebug` 的 `"" + msg` 替代 `Log.d(tag, msg)`（Android 对 null msg 同样渲染成 `null`，且这是项目 `LOG.kt` 的既有写法） | 登记不改 |

**子代理逐点确证等价的部分**（无需改动）：split 全走 `RegexUtils.getPattern(x).split(y)`；`getBytes()`/`toLowerCase()` 全对齐 `Charset.defaultCharset()`/`Locale.getDefault()`；`replaceAll(regex,"$1")` ≡ `Regex.replace(...,"\$1")`；反射 vararg 全 `*args`；okhttp 5 的 `toHeaders`/`toMediaTypeOrNull`/`toRequestBody`/`toHttpUrlOrNull`/`.dispatcher`/`.body` 替换的 null 边界与抛点一致；装箱 `==`/拆箱点、`toInt()` ≡ `Integer.parseInt`、`and 0xFF` ≡ `& 0xFF`、Base64 flag 组合、`ArrayList(rules.toList())` ≡ `new ArrayList<>(Arrays.asList(...))`、`removeAt(0)` 按下标删、`getMethod`/`getDeclaredConstructor`/`declaredClasses`/`getMethods` 同源同序、`switch`→`when else`、companion 初始化顺序 —— 全部一致；`JsSpider`/`Global`/`Trans`/`Crypto`/`Async`/`FunCall`/`local`/`OkHttp`/`Proxy` 全类逐方法无差异。

**收敛结论**：第 3 轮（修复后的干净轮）**无 阻断/高/中**，剩余发现全属**低（不可达或仅异常类型/点位）**或**口味** ⇒ 达到计划规定的收敛终止线（"连续一轮没有 阻断/高/中，且剩余全部属既有问题或口味差异"）。
